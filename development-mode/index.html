실전 홈페이지 제작

Practice Mode에서 구조와 기능을 검증한 뒤, 실제 회사 데이터와 실제 도메인으로 프로덕션 홈페이지를 제작합니다. 패턴은 이미 검증했으므로 설명보다 실행 속도에 집중합니다.

실제 데이터 실제 도메인 Practice 코드 재사용 3주 축소 로드맵

시작 조건

Practice Mode의 Definition of Done이 모두 충족된 상태에서 시작합니다 — 더미 데이터 기준 7페이지·2폼·다운로드가 스테이징에서 전부 동작하고, 핵심 로직을 스스로 설명할 수 있어야 합니다.

Practice → Development 이관 전략

추천: Practice Mode 코드베이스를 복사해 새 프로젝트로 시작 → 더미 데이터를 실제 데이터로 교체.
이미 동작이 검증된 구조(스키마, Server Action, 파일 업로드, 이메일 발송)를 재사용하는 편이 처음부터 다시 짜는 것보다 빠르고 안전합니다. Claude Code에게 "practice-mode 코드를 development-mode로 옮기면서 더미 데이터/문구만 실제 값으로 교체해줘"라고 맡길 수 있습니다.

실전 준비 체크리스트

실제 콘텐츠

  • 회사소개 문구, 연혁, 비전/미션
  • 로고, 대표 이미지
  • 사업분야별 소개 문구
  • 제품 목록·사양·이미지
  • 카탈로그·데이터시트 PDF
  • 실제 담당자 연락처·수신 이메일
  • 사업자 정보(상호·사업자등록번호·주소 — 푸터용)
  • 개인정보처리방침 문구

실전 전환 작업

  • 실제 도메인 구매/연결, HTTPS 확인
  • 이메일 발신 도메인 인증(Resend 등)
  • Neon/Vercel 프로덕션 프로젝트를 Practice와 분리 생성
  • 지도 API(카카오·네이버) 실제 키 발급 및 도메인 등록
