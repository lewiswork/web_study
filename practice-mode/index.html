연습용 홈페이지 제작

실제 만들 회사 홈페이지와 동일한 구조에 더미(가짜) 데이터를 적용해보는 리허설 단계입니다. 매 단계마다 Claude Code에게 "왜 이렇게 하는지" 설명을 받으며 천천히 진행하고, 여기서 검증된 코드는 Development Mode로 그대로 옮겨갑니다.

예상 진행 기간

진행 방식 — 설명받으며 진행하기

  1. 작업 전 "이번에 만들 것 + 왜 필요한지"를 Claude Code에게 목표로 제시
  2. 코드가 생성되면 바로 다음으로 넘어가지 말고 "이 코드가 어떤 흐름으로 동작하는지" 설명 요청
  3. Postgres MCP로 실제 쿼리·스키마를 직접 열어보며 개념을 눈으로 확인
  4. 막히면 에러 메시지를 그대로 붙여넣고 원인부터 질문 (정답 코드보다 원인 이해 우선)
  5. 각 주차 끝에 "이 부분을 내가 직접 설명할 수 있는가"를 스스로 체크

더미 콘텐츠 전략

실제 콘텐츠 대신 아래와 같은 플레이스홀더 데이터셋을 먼저 준비합니다. 실제 회사 정보가 아직 없어도 지금 바로 시작할 수 있습니다.

  • 가상 회사명 1개 (예: "○○테크")
  • 가상 제품 3–5개 (이름, 카테고리, 짧은 설명, 이미지 placeholder)
  • 샘플 자료 PDF 2–3개 (아무 문서나 더미로 사용 가능)
  • 가상 사업분야 2–3개
